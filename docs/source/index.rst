Iragi Documentation
===================

**Iragi** est un package Python modulaire dédié à l'inspection, à l'extraction et à l'analyse de fichiers.
Il réunit deux moteurs indépendants — **Scan** et **PDF** — et propose un troisième module, **All**,
qui orchestre leur fonctionnement dans un pipeline unifié.
